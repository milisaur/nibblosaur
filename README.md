# Nibblosaur

**A tiny dinosaur with big feelings.**

Nibblosaur is a small, open-source virtual pet game written in Java.

Meet Heinrich, your very own little dinosaur. Feed him, play with him, help him rest, and discover how his mood changes throughout the day.

## Features

- Interactive terminal-based gameplay
- Feed, play, and sleep actions
- Three needs: satiety, happiness, and energy
- Dynamic moods based on Heinrich's needs
- Randomized mood reactions
- Experimental ASCII terminal animations

## Getting Started

### Requirements

- Java Development Kit (JDK) 25
- Apache Maven

### Installation

Clone the repository:

```bash
git clone https://github.com/milisaur/nibblosaur.git
cd nibblosaur
```

Compile the project:

```bash
mvn clean compile
```

Run the game:

```bash
java -cp target/classes de.milisaur.nibblosaur.Main
```
